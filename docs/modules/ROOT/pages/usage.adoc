= Utilisation

== 🐍 En tant que bibliothèque Python

[source,python]
----
from french_typo import format_text

text = "Voir n°4 : 10 KM et article 5."
result = format_text(text, add_nbsp_enabled=True)

print(result)
# Voir n<sup>o</sup>&nbsp;4&nbsp;: 10&nbsp;km et article&nbsp;5.
----

`add_nbsp_enabled` insère les espaces insécables (`&nbsp;`) ; désactivé par défaut.

== ⌨️ Via la CLI

French Typo fournit une commande `french-typo` pour corriger des fichiers AsciiDoc.

[source,bash]
----
french-typo mon_fichier.adoc
----

Ou récursivement sur un dossier :

[source,bash]
----
french-typo docs/
----

Les fichiers sont modifiés *in place*. L'option `--nbsp` active les espaces insécables (désactivée par défaut pour AsciiDoc).

== 🔌 Intégrations

=== Anki

L'adaptateur Anki (`french_typo.adapters.anki.formatter.format_anki_html`) applique la typographie
au HTML des champs de notes :

* gestion des cloze (`{{c1::...}}`) et du HTML ;
* espaces insécables adaptés au rendu Anki.

L'add-on Anki qui consomme cet adaptateur vit dans un dépôt séparé :
https://github.com/dhrions/anki-french-typo[anki-french-typo]. Le moteur ne dépend pas d'`aqt`.

=== AsciiDoc

L'adaptateur AsciiDoc (`french_typo.adapters.asciidoc.formatter.format_asciidoc_file`) permet de corriger automatiquement :

* les paragraphes standards ;
* en ignorant les blocs littéraux (`----`) ;
* en ignorant les commentaires (`//`) ;
* en ponctuant les listes (`;` pour les items intermédiaires, `.` pour le dernier).
