= French Typo
:page-description: Moteur de correction typographique française (core Python, CLI, intégrations Anki/AsciiDoc).

image::french-typo.png[French Typo,width=300,align=center]

== ⚡ TL;DR

Applique les règles typographiques françaises usuelles (espaces insécables, unités, ordinaux,
guillemets, abréviations) via un core Python pur, que reprennent une CLI pour les fichiers
AsciiDoc et un adaptateur pour les notes Anki. La CLI réécrit les `.adoc` en place sans toucher
aux blocs littéraux, commentaires, titres ni attributs, et n'ajoute les espaces insécables
qu'avec `--nbsp`.

🎯 Quand : pour la seule typographie ; sur une doc AsciiDoc, `adocx` (dépôt `asciidoc-utils`)
y ajoute ses règles éditoriales et la vérification des liens.

[source,bash]
----
pip install french-typo
# corriger en place un fichier ou un dossier AsciiDoc
french-typo docs/
----

== 📐 Règles appliquées

Règles typographiques françaises usuelles, conformes au
link:https://les-unpertinents.fr/Manuscrits/Lexique%20des%20r%C3%A8gles%20typographiques%20en%20usage%20%C3%A0%20l%27Imprimerie%20nationale2.pdf[lexique de l'Imprimerie nationale] :

* espaces insécables avant les ponctuations doubles (`: ; ? ! % €`),
* normalisation des unités (`KM` → `km`, `KG` → `kg`, etc.),
* formatage des ordinaux (`1er` → `1<sup>er</sup>`, `n°4` → `n<sup>o</sup>4`),
* suppression des espaces multiples,
* gestion des guillemets français doubles et simples (« » et ‹ ›),
* espaces insécables après les abréviations usuelles (`M. Dupont`, `Dr Martin`, `St Étienne`).

== ✨ Fonctionnalités principales

* Moteur typographique indépendant (sans dépendance UI)
* API Python simple et stable
* Interface en ligne de commande pour AsciiDoc
* Intégration Anki (HTML + cloze)
* Tests unitaires couvrant le core
